# 119파이어 AI 자동업무비서 V3

`com.fire119.assistant` · Android 8.0 이상 · 문병민님 개인용 현장 업무비서

V3의 기준은 **사용자가 입력하기보다, 앱이 실제 업무 자료를 찾아 정리하고 애매한 것만 확인받는 것**입니다. 기존 V2 Room DB(`119fire_work_v2.db`)와 기능은 지우지 않으며, V3 마이그레이션으로 새 필드와 테이블만 추가합니다.

## 실제 동작하는 V3 흐름

1. 갤럭시 통화기록과 사용자가 허용한 삼성 통화녹음 폴더를 확인합니다.
2. 새 녹음은 중복 없이 AI 전사·요약 대기열로 저장합니다. 앱이 통화를 직접 녹음하지 않습니다.
3. 전화번호가 같으면 기존 고객 기록에 연결하고, 새 문의·현장·할 일 후보를 로컬 DB에 저장합니다.
4. 앱 카메라 사진은 즉시 현장에 저장합니다. 선택하면 Samsung 기본 카메라의 새 사진도 탐색합니다.
5. 공사중 현장이 정확히 하나일 때만 기본 카메라 사진을 해당 현장에 자동 연결합니다. 둘 이상이거나 불확실하면 `확인할 것 Inbox`에 넣습니다.
6. 현장 마감은 사진·작업기록·블로그 준비도를 먼저 보여주고, 사용자가 마지막 확인을 눌러야 `공사완료`가 됩니다.
7. 견적은 사용자가 저장한 품목·규격·수량·단가만으로 계산합니다. 동일 제목을 다시 저장하면 V1, V2, V3… 이력을 보존합니다.

## V3에서 추가된 실제 데이터

- 고객: 업체명, 담당자, 지역, 주소
- 현장: 방문·시작·완료 시각, 재방문 메모
- 음성메모: 현장별 원문과 저장 시각
- 견적: 규격, 버전 스냅샷, 즐겨찾기 품목, 특기사항 문구
- 자동화: 사진/통화/Drive 후보의 `대기 · 확인필요 · 완료 · 실패` 상태

## 최초 1회 설정

1. **통화녹음 자동 확인**: 앱 설정에서 삼성 기본 통화녹음 폴더를 선택합니다.
2. **전화기록 자동 연결**: `READ_CALL_LOG` 권한을 허용합니다. 통화 내용이나 녹음은 이 권한만으로 전송하지 않습니다.
3. **삼성 카메라 사진 자동 확인**: 사진 권한을 허용합니다. 원본은 삭제·이동하지 않으며, 새 `DCIM/Camera` 사진 메타데이터만 읽습니다.
4. **AI 비서 연결**: 설정 → `AI 비서 연결`에서 Netlify 주소와 `APP_ACCESS_CODE`만 저장한 뒤 `AI 연결 확인`을 누릅니다. OpenAI API Key는 APK에 넣지 않습니다.
5. **Google Drive 연결**: 설정 → `Google Drive 연결`에서 `현장자료 상위 폴더 주소`를 붙여 넣습니다. 앱은 주소의 폴더 ID를 사용해 해당 폴더 아래에 `연도 → 월 → 현장명` 구조로 업로드합니다. AI 서버 연결을 함께 쓰거나, 필요하면 Drive 전용 서버 주소·접속 코드를 따로 저장합니다. [Google Drive OAuth 설정](docs/GOOGLE_DRIVE_OAUTH.md)을 한 번 완료한 뒤 `실제 연결 확인`을 누릅니다.

## Google Drive 원칙

- Drive가 실제 사진·견적서·문서 원본 보관소가 되는 구조를 준비합니다.
- 기존 `2026년도 / 9월 / 현장명` 같은 폴더를 이동하거나 일괄 변경하지 않습니다.
- 기존 현장명 폴더를 먼저 찾고, 없는 폴더는 **확실할 때만** `연도 → 월 → 현장명` 생성 후보로 만듭니다.
- Drive OAuth가 연결되기 전에는 로컬 DB의 `Drive 업로드 대기` 상태까지만 만들며, 업로드 성공인 척 표시하지 않습니다.

## Android/정책 제한

| 기능 | 상태 | 방식 |
| --- | --- | --- |
| 삼성 기본 통화녹음 탐색 | 조건부 자동 | SAF 폴더 권한 + WorkManager 약 15분 확인 + 수동 즉시 확인 |
| 통화기록 연결 | 조건부 자동 | Android 통화기록 권한 후 번호·시각 메타데이터만 인덱싱 |
| 기본 카메라 사진 탐색 | 조건부 자동 | 사진 권한 후 새 Camera 사진 탐색. Android의 사진 권한 범위 안에서만 가능 |
| 사진 현장 연결 | 자동 + 확인 | 공사중 현장 1개면 자동, 그 외는 확인함 |
| Drive 업로드/폴더 생성 | OAuth 연결 후 조건부 자동 | 기존 폴더 우선 검색, 중복 생성 금지 |
| 견적 PDF | 자동 초안 | 금액·발송은 사용자 최종 확인 필요 |
| 문자·카카오톡·이메일 발송 | 자동 발송 안 함 | 사용자 최종 확인 후 별도 실행 |

## 빌드

`v3` 브랜치 푸시 시 GitHub Actions **Build 119Fire APK**가 `app-debug.apk`를 만듭니다.

GitHub → Actions → 성공한 실행 → Artifacts → `119fire-hybrid-apk`

디버그 APK는 CI마다 서명이 달라질 수 있습니다. 이전 디버그 버전이 설치되어 있다면 제거 후 설치하세요.
